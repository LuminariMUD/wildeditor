# 2024–2025 documentation snapshot

This directory preserves the documentation tree and service notes superseded by the canonical guides in [`docs/`](../../README.md). It is retained for project history, not for setup, deployment, security, testing, or API instructions.

The top level contains earlier cross-project guides, plans, status reports, checklists, and changelogs. Subdirectories preserve the former `agent/`, `backend/`, `frontend/`, `mcp/`, `project/`, and `context/` groupings. `service-notes/` contains documentation and command references formerly stored beside application code, scripts, and root probes.

Paths and links inside the snapshot have not been rewritten. Credential-like literals were redacted from the archived copy, but any value that ever appeared in repository history must still be treated as exposed and rotated.
